# Чужой трон

Мини-шахматы на поле 4×4: у каждого король, ладья и страж. Нужно посадить короля на трон соперника и пережить один ответный ход. Один HTML-файл без внешних библиотек и сетевых запросов.

Игра просчитана полностью: при безошибочной игре обеих сторон — ничья, цвет не даёт преимущества.

## Правила

- **Расстановка.** Белые: страж a1, король b1, ладья d1. Чёрные: ладья a4, король c4, страж d4 (поворот на 180°).
- **Ходы.** Король — на одну клетку в любую сторону. Ладья — по прямой на одну или две клетки, через фигуры не прыгает. Страж ходит как король, но это обычная фигура: его можно взять, шах ему не объявляют. Ходить под шах нельзя, королей не берут.
- **Троны.** У белых b2 и c2, у чёрных b3 и c3. Свой трон ничего не даёт — побеждают на чужом.
- **Победа троном.** Если игрок начинает ход, а его король стоит на троне соперника и не под шахом, он победил. То есть нужно встать на трон и пережить один ответ; сорвать захват можно только шахом.
- **Мат** — тоже победа.
- **Одни короли** — не ничья: партия продолжается как гонка королей к тронам.
- **Ничья:** пат, троекратное повторение позиции или 40 полуходов подряд без взятия.

## Что известно о балансе

Все достижимые позиции решены ретроградным анализом (`src/solver.js`): с учётом симметрий их 1 046 490.

- Начальная позиция ничейна.
- Из восьми первых ходов белых семь сохраняют ничью; проигрывает только Лd1–d3 (чёрные выигрывают за 13 полуходов).
- Самый длинный форсированный выигрыш — 36 полуходов, поэтому лимит в 40 полуходов без взятия не отнимает ни одной победы.
- Набор «король, ладья, страж» ничеен при любой симметричной расстановке на первой горизонтали.

Анализ не учитывает историю партии (повторения и счётчик полуходов без взятия): это правила ничьей, и на оценку «выигрыш/не выигрыш» они при таком лимите не влияют.

## Игра с компьютером

Компьютер ходит по решённой таблице. Уровень — это доля ходов, сделанных наугад:

| Уровень | Случайных ходов |
|---|---|
| Новичок | 30% |
| Любитель | 12% |
| Мастер | 4% |
| Безупречный | 0% — выиграть нельзя, можно только не проиграть |

Переключатель «Показывать точную оценку» раскрашивает ходы выбранной фигуры (зелёный — надёжный, красный — ухудшает позицию, золотой — выигрывает) и отмечает ошибки в записи партии: `?` — упущен выигрыш, `??` — ход ведёт к проигрышу. После конца партии разбор показывается всегда.

Таблица считается в браузере в фоновом потоке за несколько секунд и сохраняется в IndexedDB; пока она не готова, компьютер играет неглубоким перебором.

## Разработка

```bash
npm test
```

```bash
npm run build
```

Сборка пишет `docs/index.html` — его же отдаёт GitHub Pages (Settings → Pages → ветка `main`, папка `/docs`). Файл открывается и просто с диска.

- `src/engine.js` — правила.
- `src/solver.js` — решение игры и поиск позиции в таблице.
- `src/bot.js` — выбор хода и разбор.
- `src/app.js`, `src/style.css`, `src/template.html` — интерфейс.
- `tests/` — правила, согласованность таблицы, игра ботов.
